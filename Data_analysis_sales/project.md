# Project: Grocery Sales Analysis

## Purpose

Explore the Supermart Grocery Sales retail dataset and publish the findings as
a portable HTML report.

## Key files

- `script/sales_analysis.py` performs the analysis.
- `script/build_html_report.py` builds `sales_findings.html`.
- `data/` holds the source CSV used for reproducible analysis.
- `outputs/` receives generated tables, summaries, and charts.
- `requirements.txt` lists the Python dependencies.

## Workflow

Follow the commands and date-parsing notes in [README.md](./README.md). Run
scripts with the project's `.venv` when available. Generated analysis output,
virtual environments, Python caches, and duplicate source archives are ignored
by `.gitignore`.

## Change guidance

Keep the report reproducible from the source data and analysis scripts. Do not
commit private or newly downloaded datasets without explicit approval.
