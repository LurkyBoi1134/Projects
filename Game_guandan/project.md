# Project: Guandan

## Purpose

Provide a playable browser-based implementation of the Guandan card game.

## Key files

- `index.html` contains the game styles and logic.
- `requirements.txt` is present in the project; consult it before changing
  Python-related tooling.

## Preview and validation

Follow [README.md](./README.md). The game page is self-contained and requires no
build step, package installation, or external assets. Open `index.html` in a
modern browser to test gameplay.

## Change guidance

Keep game rules and state handling consistent, and manually verify the
affected gameplay paths in the browser after changes.
