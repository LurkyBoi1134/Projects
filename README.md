`.gitignore`. Check a project's README for run and preview instructions before
making changes.

## Working in this repository

- Keep changes scoped to the relevant project unless a change explicitly spans
  projects.
- Prefer each project's existing tools and conventions; do not add dependencies
  to standalone HTML projects without a clear need.
- Review the applicable `AGENTS.md` and project documentation before editing.
- Avoid committing generated output, local environments, or private source data;
  project-level `.gitignore` files document the local exclusions.
