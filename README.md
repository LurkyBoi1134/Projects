# Projects

This repository contains small standalone projects, prototypes, and learning
resources. The web projects are published from their subfolders through GitHub
Pages.

## Projects

| Folder | Description |
| --- | --- |
| [`Data_analysis_sales/`](./Data_analysis_sales/) | Exploratory analysis of grocery sales data and a self-contained HTML report. |
| [`Floor_pulse/`](./Floor_pulse/) | A static prototype for discovering campus activities and connecting with people. |
| [`Game_flight/`](./Game_flight/) | Skyward Run, a browser flight game. |
| [`Game_guandan/`](./Game_guandan/) | A browser-based Guandan card game. |
| [`Knowledge_base/`](./Knowledge_base/) | A CS 61A first-time learner's field guide. |

Each project folder has its own `README.md`, `project.md`, and `.gitignore`.
Check its README for project-specific run and preview instructions before
making changes.

## Working in this repository

- Keep changes scoped to the relevant project unless a change explicitly spans
  projects.
- Prefer each project's existing tools and conventions; do not add dependencies
  to standalone HTML projects without a clear need.
- Review the applicable `AGENTS.md` and project documentation before editing.
- Avoid committing generated output, local environments, or private source data;
  project-level `.gitignore` files document the local exclusions.
