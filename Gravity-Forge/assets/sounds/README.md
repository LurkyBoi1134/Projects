# Sounds

All audio in Gravity Forge is **generated procedurally at runtime** with the
Web Audio API — background music, jump blips, gravity whooshes, laser hums,
checkpoint chimes, the victory fanfare… everything. There are no audio files
to download, so the game loads instantly and works fully offline.

If you'd like to replace a sound with your own sample, drop the file here
(e.g. `jump.mp3`) and load it in `script.js` → `AudioManager`.
