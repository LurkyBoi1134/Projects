# Skyward Run

A browser flight game published at
https://lurkyboi1134.github.io/Projects/Game_flight/.

## Preview

[Open the game](./index.html) in a modern browser. It is a standalone page and
does not require a build step or package installation.

On phones, drag on the playfield to steer and fly; use the pause and fire
buttons at the bottom right. Use the speaker button to mute or enable sound
effects. On desktop, use the arrow keys or WASD to move and Space to fire.

To play without the browser address bar, add the game to your phone's Home
Screen and launch it from its icon. On iPhone, use Safari's Share menu and
choose **Add to Home Screen**. On Android, use the browser menu and choose
**Install app** or **Add to Home screen**. Opening the link in a regular browser
tab will continue to show the browser's address bar.

## Files

- `index.html` contains the game.
- `manifest.webmanifest` configures standalone Home Screen installation.
- `icon.svg` is the source artwork for the app icons.
- `project.md` records the project scope and editing guidance.
- `.gitignore` excludes local operating-system and editor files.
