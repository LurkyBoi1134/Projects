# Skyward Run

Remote repository: https://github.com/LurkyBoi1134/Projects.git
Play the game: https://lurkyboi1134.github.io/Projects/Game_flight/

## Purpose

A standalone browser game about flying through a scrolling environment.

## Key files

- `index.html` contains the game markup, styles, and client-side behavior.

## Preview and validation

Open `index.html` in a modern browser. There is no build step or package
installation. Check gameplay and responsive behavior in the browser after
changes.

## Change guidance

Keep the game self-contained unless a requested feature clearly needs
additional assets or tooling. Preserve keyboard, pointer, and touch behavior
where applicable.
