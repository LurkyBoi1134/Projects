# Repository guidance

- Read the target project's `README.md`, `project.md`, and `.gitignore` before
  changing files in that project.
- Keep edits focused on the requested project; do not reformat or redesign
  unrelated projects.
- Preserve the lightweight, self-contained approach used by the static web
  projects. Add a build system or dependency only when the task requires it.
- Do not add generated output, local environment files, credentials, or private
  datasets to version control.
- Update the project's documentation when its behavior, setup, or structure
  changes.
- Run the smallest relevant validation available and report any validation that
  could not be run.
