# Four-player Luzhanqi

## Purpose

Build a self-contained browser prototype of four-player Luzhanqi (四国军棋),
with the human player fixed as South and North, East, and West controlled by
the computer.

## Files

- `index.html` contains the game UI and logic.
- `rule.md` documents the selected rules and deliberate prototype limitations.

## Guidance

Keep the implementation dependency-free. Keep the board topology, movement,
battle resolution, visibility, and documented rules consistent when extending
gameplay.
