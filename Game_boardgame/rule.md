# 四国军棋规则（本原型采用）

四国军棋规则参考[中文维基百科「四国军棋」](https://zh.wikipedia.org/zh-hans/%E5%9B%9B%E5%9B%BD%E5%86%9B%E6%A3%8B)，棋盘布局参考该词条展示的[军棋棋盘图](https://commons.wikimedia.org/wiki/File:Junqi_Gameboard.svg)。这是单人模式：玩家固定为南方，北、东、西由电脑控制。

## 阵营与朝向

- 四人分别坐北、东、南、西。
- 北与南为一队，东与西为另一队；对面玩家是队友。
- 顺时针轮流行动：北、东、南、西；每局从南方玩家开始。
- 每方的前方朝棋盘中央：北方朝南，南方朝北，东方朝西，西方朝东。
- 每回合只能移动当前玩家自己的棋子；不得吃队友棋子。电脑回合自动行动。

## 棋盘布局

- 四方各有30个停靠点；中央交会区的站点按5×5网格定位。
- 中央区域共9个停靠点：四边各3个站点，角上的端点由相邻两边共享，再加正中央1个。四边中点是4个行营。
- 每边的3个停靠点在一条直线上：两端各1个共享角站，中间1个行营；正中央另有1个普通站点。
- 中央周边站点以公路相连；四个行营分别通过铁路连接正中央站点。
- 每方前排最外侧的两个站点分别与中央一侧的两个角站直线相连；前排中间站点连接该侧中央蓝色行营。
- 相邻方阵之间的四个拐角处，各以一条朝中央区域弯曲的弧线连接双方最近的前排站点，形成类似城市道路右转车道的弯道。
- 中央四个行营保持圆形，直径与外围红色站点方块的宽度相同。
- 四个外围方阵向外错开一排，与中央九宫之间保留一排空位；连接铁路跨过空位接入九宫，避免外围区域和九宫站点重叠。
- 棋盘图中的黑线表示公路，黄色线表示铁路，蓝色圆点表示行营，绿色位置表示大本营。
- 网页的坐标和线路按这一布局表达；由于是交互原型，线路网络为简化实现。

## 棋子与布阵

每方25枚棋子：

| 棋子 | 数量 | 等级 |
| --- | ---: | ---: |
| 司令 | 1 | 9 |
| 军长 | 1 | 8 |
| 师长 | 2 | 7 |
| 旅长 | 2 | 6 |
| 团长 | 2 | 5 |
| 营长 | 2 | 4 |
| 连长 | 3 | 3 |
| 排长 | 3 | 2 |
| 工兵 | 3 | 1 |
| 炸弹 | 2 | 特殊 |
| 地雷 | 3 | 特殊 |
| 军旗 | 1 | 特殊 |

- 棋子只能布在己方阵地的兵站或大本营；行营不可布子。
- 军旗必须放在己方最后一排两个大本营之一。
- 地雷只能放在己方最后两排（靠己方后方的一端）。
- 炸弹不能放在最前排。
- 军旗和地雷不能移动；大本营上的棋子不能移动。
- 网页自动生成随机合法布阵；地雷落在本地行号第0或第1排，军旗落在第0排的大本营。

## 明暗方式

- **四暗（默认）**：各方不能看到其他玩家未翻开的棋子。
- **双明**：可见对家（对面队友）的棋子。
- **全明**：四方棋子全部可见。
- 棋子交战时翻开，之后保持公开；司令阵亡时翻开该方军旗。

## 移动

- 公路每回合只能走一站。
- 任意可移动棋子都可以沿连续铁路行进多站，直到遇到有棋子的站点；棋子不能越过阻挡。
- 沿铁路行进时可以经过铁路转弯，不限工兵。
- 铁路行程结束后，可以沿相邻公路再走一站攻击或停靠；公路不能作为中途继续行进的路线。
- 各方前排横线与内部铁路相连，因此可从本方铁路经中央铁路驶向其他方阵。
- 本方前排的左、中、右铁路连接依次接入中央对应的左、中、右站点。
- 不可走入己方棋子所在的位置。
- 行营内的棋子不可被攻击；大本营和地雷上的棋子不可移动。

## 交战

- 普通棋子由大至小：司令、军长、师长、旅长、团长、营长、连长、排长、工兵。
- 大棋吃小棋；相同等级相遇时双方同归于尽。
- 工兵能吃地雷；其他棋子遇地雷阵亡。
- 炸弹与任何棋子相遇时双方同归于尽。
- 任何棋子都可以夺取军旗。
- 不能攻击行营内的棋子。

## 胜负

- 军旗被夺或一方没有可移动棋子时，该玩家出局。
- 一队的两名玩家都出局时，另一队获胜。
- 若双方都认为无法攻灭对手，可议和。

## 原型范围

网页支持南方单人对战北、东、西三方电脑、四暗/双明/全明、随机布阵、铁路移动、交战和队伍胜负判定；尚未实现手动布阵、线上联机和裁判模式。
