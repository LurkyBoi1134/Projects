# Project: Floor Pulse

## Purpose

Prototype a friendly campus activity feed that helps people discover events and
find others with shared interests.

## Key files

- `index.html` is the standalone page and contains its styles and interactions.

## Preview and validation

Open `index.html` directly in a modern browser. There is no build step or
package installation. Check the page at desktop and narrow/mobile widths after
changing layout or interactions.

## Change guidance

Keep this prototype self-contained unless a requested feature clearly needs
additional assets or tooling. Preserve responsive behavior and accessible
controls.
