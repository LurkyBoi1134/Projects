# Floor Pulse

A static prototype for finding campus activities and meeting people through a
live activity feed, event cards, and lightweight interaction prompts.

## Preview

Open `index.html` in a modern browser. The page is self-contained and does not
require a build step or package installation.

## Files

- `index.html` contains the page markup, styles, and client-side behavior.
- `project.md` records the project scope and editing guidance.
- `.gitignore` excludes local operating-system and editor files.
