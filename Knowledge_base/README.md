# Knowledge Base

A collection of learning resources. The current page is a CS 61A field guide
and first-time learner runbook.

## Preview

Open `cs61a.html` in a modern browser. It is a standalone HTML document and
requires no build step or package installation.

## Files

- `cs61a.html` contains the CS 61A guide.
- `project.md` records the folder's scope and editing guidance.
- `.gitignore` excludes local operating-system and editor files.
