# Project: Knowledge Base

## Purpose

Keep self-contained learning guides and reference material, beginning with a
CS 61A runbook for first-time learners.

## Key files

- `cs61a.html` is the current CS 61A field guide. Its content and presentation
  are contained in a standalone HTML file.

## Preview and validation

Open `cs61a.html` in a modern browser. Check links, section navigation,
readability, and responsive layout when editing the guide.

## Change guidance

Keep educational content clear and internally consistent. Attribute external
resources and preserve the standalone nature of the current page.
